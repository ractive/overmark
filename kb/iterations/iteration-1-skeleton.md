# Iteration 1: skeleton

## Scope

- Bun, TypeScript 7 and Biome as in tab-mcp, exact pins; `bun run verify` (Biome CI,
  type check, tests) and `bun run fix`.
- `scripts/build.ts`: bundles `src/background.ts` (module), `src/content/index.ts`
  (classic script) and the side panel (`src/sidepanel/index.html`) into `dist/`, writes
  `manifest.json` from `package.json`'s version with the `key` from `manifest-key.txt`
  (`--store` leaves it out, `--test` adds `<all_urls>` host permissions for the
  end-to-end test), copies the icons. `bun run zip` packs `dist/` with Overmark's own zip
  writer.
- Manifest V3: `activeTab`, `scripting`, `sidePanel`, optional `<all_urls>`, the side
  panel, the icon, the shortcut Alt+Shift+O.
- Service worker: a click on the icon opens the side panel and injects the content
  script into that tab.
- Side panel: the page in front and a button that toggles the overlay.
- Content script: an empty overlay in a shadow DOM that can be shown and hidden; injected
  twice, it stays one instance.
- Icons generated by `scripts/icons.ts` (own PNG encoder), committed.
- CI on GitHub Actions with Chrome for Testing (branded Chrome ignores
  `--load-extension`); locally Playwright's Chromium or `CHROME_PATH`.
